# 传输速率测试

## 1. 测试环境

| 项 | 值 |
|---|---|
| 服务端 | 虚拟机（Debian 12）/ 本机(WSL) |
| 客户端 | 虚拟机本机（127.0.0.1）/ 本机(WSL) |
| 编译器 | clang++ 14.0.6 |
| 消息编码 | JSON（UTF-8） |
| 协议层上限 | 4 MiB |
| 业务层上限 | 1 MiB |

## 2. 测试变量

| 变量 | 取值 | 说明 |
|---|---|---|
| 消息大小 | 1 KiB / 64 KiB / 1 MiB | 小 / 中 / 大 |
| 发送模式 | 私发 / 群发 | 单目标 / 多目标 |
| 接收者数 | 1（私发）/ 3（群发） | — |
| 发送者数 | 1 | 模拟"话痨" |
| 持续时间 | 10 秒 | 预热 2 秒后开始计时 |
| 编译模式 | Debug / Release | - |

## 3. 测试场景

| 编号 | 消息大小 | 模式 | 接收者数(不含自身) |
|---|---|---|---|
| A1 | 1 KiB | 私发 | 1 |
| A2 | 64 KiB | 私发 | 1 |
| A3 | 1 MiB | 私发 | 1 |
| B1 | 1 KiB | 群发 | 3 |
| B2 | 64 KiB | 群发 | 3 |
| B3 | 1 MiB | 群发 | 3 |

每组跑 3 次，取平均。

## 4. 测试指标

| 指标 | 定义 |
|---|---|
| 吞吐量 | 接收端每秒收到的字节数 |
| QPS（条/秒） | 每秒成功处理的消息条数 |
| 发送字节数 | 发送端每秒发出的字节数 |
| 接收字节数 | 接收端每秒收到的字节数 |

## 5. 测试逻辑

1. 启动 1 个发送者，N 个接收者，全部登录。
2. 接收者开线程持续读取，统计收到的字节数。
3. 发送者持续发送固定大小的消息，持续 T 秒。
4. 计时结束后，统计：
   - 发送总字节数 / T
   - 接收总字节数 / T

### 说明：
1. 表格中的“服务端吞吐量”，统计的是测试脚本中 3 个纯接收者实际收到的数据量总和。
    
2. 在群发模式下，服务端为了广播，实际上还会给发送者本人发送一份回显。因此，服务端真实的物理出口带宽压力大约是表格数值的 4/3 倍（例如虚拟机场景 6 中，物理带宽压力约为 4.27 × 4/3 ≈ 5.68 MiB/s，即 45 Mbps）。
    
3. 私发模式下，由于没有回显，统计数值即为真实物理吞吐量
